# RentPass: ステークホルダー別バリュープロポジション (Value Proposition)

RentPassは、賃貸借契約に関わる4つの主要ステークホルダー（入居希望者、賃貸オーナー、管理会社、仲介会社）それぞれに対して明確な価値を提供します。

## 1. 入居希望者 (Tenants) への提供価値

### ペルソナと課題
- **単身高齢者**: 年金収入はあるが、「年齢」「孤独死リスク」「連帯保証人不在」で内見すら断られる。
- **フリーランス・クリエイター・個人事業主**: 確定申告上の経費控除で所得が低く見え、直近の入居審査で落とされる。
- **ナイトワーク・水商売従事者**: 現金・預貯金資産は潤沢にあるが、勤務形態や収入証明の性質上、大半の保証会社で弾かれる。
- **外国人労働者・留学生**: 日本語コミュニケーションや習慣の違い、保証人不在で入居困難。

### RentPassによる解決策
1. **「断られない」条件の事前設計**: 自分が提供可能な対策（例: 家賃6ヶ月前払い、週2回の安否確認ボタン押下、残置物放棄合意）をパッケージ化して提示可能。
2. **ワンタップ安否確認**: アプリやLINEからの負担のない挨拶チェックインで自立した生活を継続。
3. **安全な家賃リザーブ**: 信託・収納代行による適正な保全で、多額の現金を直接大家に手渡しするリスクを排除。

---

## 2. 賃貸オーナー (Landlords) への提供価値

### 課題
- 空室期間が長引いて利回りが悪化しているが、孤独死による心理的瑕疵（事故物件化）や、滞納・残置物放置による裁判・撤去費用（数十万〜数百万円）が怖くて受け入れられない。

### RentPassによる解決策
1. **確実な家賃回収**: 信託保全された家賃リザーブまたは保証会社連携により、最大1年先までの家賃が担保される。
2. **孤独死・事故物件化の徹底防止**: 日々の安否確認ログと未応答時の早期駆けつけ体制により、異常発生から早期発見が可能。
3. **残置物撤去の迅速化**: 国交省ガイドライン準拠の電子委任契約により、相続人捜索や法的手続きによる空室長期化を防止。

---

## 3. 賃貸管理会社 (Property Management) への提供価値

### 課題
- オーナーに対して「この入居者をなぜ受け入れて良いか」を論理的に説明・説得できない。
- 入居後の安否確認や緊急時対応を自社スタッフで行うリソースがない。
- 審査NGとなった顧客へのフォローができず、成約チャンスを失っている。

### RentPassによる解決策
1. **リスク対策証明書（RentPass）の自動生成**: オーナーへの提案資料としてそのまま利用可能な信用サマリーを出力。
2. **見守り・アラート業務の自動化**: 自動通知と提携支援法人の活用により、管理会社の日常運用コストを最小化。
3. **改正住宅セーフティネット法対応**: 2025年施行の「居住サポート住宅」登録要件をシステム的にクリア。

---

## 4. 不動産仲介会社 (Broker / Real Estate Agents) への提供価値

### 課題
- 苦労して内見案内した顧客が、保証会社や管理会社の審査で落ちて成約手数料（仲介手数料）がゼロになる。
- 審査に通りにくい顧客の物件探しに膨大な時間と労力がかかる。

### RentPassによる解決策
1. **成約率（CVR）の劇的改善**: 審査落ち予備軍を「条件付き成約可能案件」に転換し、仲介手数料を獲得。
2. **提案可能物件の拡大**: RentPass提携物件またはRentPass条件受け入れ可能な管理会社へスムーズに送客。
