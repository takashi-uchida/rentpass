# RentPass: ユースケース別ライフサイクル状態遷移図 (Use Case Transitions)

本ドキュメントでは、RentPassの主要3ユースケース（単身高齢者、フリーランス/ナイトワーク、安否アラート発生時）における完全な状態遷移フローを定義します。

---

## ユースケース 1: 単身高齢者の見守り付き入居フロー (Senior Tenant Flow)

```mermaid
stateDiagram-v2
    [*] --> 申請作成: 入居希望者/仲介が基本情報入力
    申請作成 --> 条件設計中: 属性「高齢単身」判定
    
    state 条件設計中 {
        [*] --> 見守りプラン選定: 毎日チェックイン設定
        見守りプラン選定 --> 残置物同意書生成: 国交省モデル条項
        残置物同意書生成 --> 居住支援法人割当: 駆けつけ受任者指定
    }
    
    条件設計中 --> 管理会社確認: RentPass(A+スコア)提示
    管理会社確認 --> オーナー承諾: リスク対策条件パッケージ承認
    オーナー承諾 --> 賃貸借契約締結: 本人・保証会社・管理会社電子締結
    賃貸借契約締結 --> 入居中_見守り稼働: 鍵引渡し・日次安否確認開始
    
    入居中_見守り稼働 --> [*]: 正常退去
```

## ユースケース 2: フリーランス・夜職の前払いリザーブ信託フロー (Nightlife / Freelancer Reserve Flow)

```mermaid
stateDiagram-v2
    [*] --> 申請作成: 属性「個人事業/夜職」選択
    申請作成 --> 資産証明提示: 口座残高/確定申告アップロード
    資産証明提示 --> リザーブ条件設定: 前払い月数(6ヶ月分)指定
    
    state 保全手続き {
        [*] --> 外部信託口座開設: エスクロー信託連携
        外部信託口座開設 --> 入金完了確認: ¥720,000 着金確認
        入金完了確認 --> 保全証明発行: RentPass Premium認証
    }
    
    リザーブ条件設定 --> 保全手続き
    保全手続き --> 審査通過: 貸主安心ステータス確立
    審査通過 --> 入居開始: 毎月自動引き落とし・オーナー払い出し
    
    state 入居運用 {
        毎月1日_家賃送金 --> 残高更新: 残存月数カウントダウン
        残高更新 --> 補充リマインド: 残り2ヶ月で追加チャージ通知
    }
    
    入居開始 --> 入居運用
    入居運用 --> 満期精算_退去: 未経過分返還
```

## ユースケース 3: 安否未応答時の段階的エスカレーションフロー (Safety Alert Escalation Flow)

```mermaid
flowchart TD
    A[毎日 10:00 安否チェックイン配信] --> B{定刻までに応答あり?}
    B -- はい --> C[ステータス: 正常 Level 0]
    B -- いいえ --> D[経過時間 12時間: Level 1 注意]
    
    D --> E[本人へSMS/プッシュ自動再督促]
    E --> F{応答あり?}
    F -- はい --> C
    F -- いいえ --> G[経過時間 24時間: Level 2 警戒]
    
    G --> H[登録緊急連絡先へ自動通知 & 管理会社アラート]
    H --> I{家族・親族と連絡がついたか?}
    I -- はい --> J[家族が安否確認・誤報解除] --> C
    I -- いいえ --> K[経過時間 48時間: Level 3 緊急]
    
    K --> L[居住支援法人 / 提携駆けつけ員へ現地確認発注]
    L --> M[現地訪問・安否確認実施]
    M --> N{現地状況判定}
    N -- 無事確認 --> O[原因確認 & アラート解除] --> C
    N -- 異変・救急搬送 --> P[救急・警察要請 & 管理会社・オーナー緊急報告]
    N -- 孤独死確認 --> Q[警察立会・残置物電子委任合意に基づく適正処理]
```
