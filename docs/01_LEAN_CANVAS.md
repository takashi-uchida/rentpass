# RentPass: リーンキャンバス (Lean Canvas)

| 項目 | 内容 |
| :--- | :--- |
| **1. 課題 (Problem)** | **入居希望者の課題**: <br>・資産や支払能力はあるが、会社員属性・源泉徴収票がないため審査に落ちる（夜職、フリーランス、個人事業主）<br>・高齢・単身であることを理由に門前払いされる（孤独死・安否不安）<br>・連帯保証人や身元引受人がいない<br><br>**貸主・管理会社の課題**: <br>・空室を埋めたいが、滞納や孤独死・残置物放置による損害（原状回復・事故物件化）が怖くて貸せない<br>・保証会社が審査NGを出すと受け入れ手段がない |
| **2. 顧客セグメント (Customer Segments)** | **Primary B2B**: 賃貸管理会社（プロパティマネジメント会社）、不動産仲介会社<br>**Secondary B2B**: 個人賃貸オーナー、居住支援法人、信託会社、家賃保証会社<br>**End User**: 審査難民予備軍（単身高齢者、フリーランス/クリエイター、水商売/ナイトワーク、外国人労働者/留学生） |
| **3. 独自の価値提案 (Unique Value Proposition)** | **「審査で断る」から「対策条件をセットして貸す」へ。**<br>支払いリザーブ（信託・保証連携）、定期安否見守り、残置物合意を統合し、貸主が懸念するすべてのリスクをクリアした「RentPass」を自動発行。 |
| **4. ソリューション (Solution)** | 1. **信用パス（RentPass）生成**: 代替与信・資産残高・身元証明の統合レポート<br>2. **安否確認・見守りエンジン**: LINE/SMS/Webによる自動チェックイン & 段階的エスカレーション<br>3. **前払い・リザーブ保全連携**: 外部信託・収納代行と連動した残高・払い出し可視化<br>4. **残置物処理・死後事務電子合意**: 国交省ガイドライン準拠の標準契約ワークフロー |
| **5. チャネル (Channels)** | ・管理会社・仲介会社向けSaaS営業（業務効率化・成約率向上フック）<br>・居住支援法人・行政窓口（セーフティネット住宅支援制度連携）<br>・家賃保証会社との共同商品化（API連携）<br>・夜職専門・外国人専門・シニア専門不動産エージェントへの導入 |
| **6. 収益の流れ (Revenue Streams)** | 1. **管理会社SaaS利用料**: 月額基本料（¥10,000〜¥50,000）+ 管理室数課金（¥300〜¥500/室/月）<br>2. **RentPass 発行・成約手数料**: 成約1件あたり ¥5,000〜¥15,000<br>3. **見守り・エスカレーション代行手数料**: 月額 ¥1,000〜¥2,500/人<br>4. **外部パートナー連携フィー**: 信託会社組成手数料、保証会社連携マージン、保険代理店手数料 |
| **7. コスト構造 (Cost Structure)** | ・システム開発・保守運用費（AWS/Supabase、インフラ、セキュリティ監査）<br>・SMS送信料 / 外部API通信費<br>・提携見守り訪問事業者・コールセンター委託費<br>・法務・信託スキーム組成コンサルティング費用<br>・B2Bセールス & カスタマーサクセス人件費 |
| **8. 主要指標 (Key Metrics)** | ・RentPass発行件数 & 成約転換率（Pass発行後の契約承諾率）<br>・管理室数（ARR / MRR）<br>・安否確認応答率 & アラート解決平均時間<br>・滞納発生率（0%維持目標） & 残置物トラブル発生率 |
| **9. 圧倒的優位性 (Unfair Advantage)** | ・法的に安全な「自社資金非保有型」信託・収納代行ハイブリッドモデル<br>・改正住宅セーフティネット法（2025年施行）に完全準拠した官民連携アーキテクチャ<br>・保証会社・信託会社・居住支援法人を巻き込んだ三位一体のエコシステム |
