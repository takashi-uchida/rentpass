# MVP-22 前払い・保証・家賃リザーブの非預託モデル

RentPassの支払い担保は重要な価値ですが、MVPでは **RentPass自身が前払い家賃・敷金・保証金を預からない** ことを明確にします。

RentPassは、資金を保有するサービスではなく、外部の管理会社、保証会社、収納代行、信託会社、保険会社のステータスを統合して、貸主が判断しやすい「支払い対策」として可視化するSaaSです。

## 設計原則

- RentPassは利用者資金を保有しない。
- RentPassは前払い可能額・支払い条件・外部連携ステータスを管理する。
- 実際の入金、収納、払い出し、返還は、管理会社・保証会社・収納代行・信託会社の既存スキームで行う。
- オーナーには「資金がどこにあり、どの条件で支払い対策になっているか」を要約表示する。
- 入居者には「誰に支払うのか」「未経過分の返還条件」「RentPassが預からないこと」を説明する。

## 2. 非預託アーキテクチャ

```text
入居希望者
  ↓
管理会社指定口座 / 保証会社 / 収納代行 / 信託会社
  ↓
管理会社・オーナー

RentPass
  └─ 入金・保証・収納・信託・保険のステータスだけを参照/記録
```

RentPassが扱うのは、以下のような **業務ステータス** です。

- 前払い可能月数
- 想定前払い額
- 支払い先種別
- 初回入金確認ステータス
- 保証会社申請ステータス
- 収納代行設定ステータス
- 家賃リザーブ/信託ステータス
- 保険申込ステータス
- オーナー向け支払い対策サマリー

## 3. 前払い条件ステータス

| Status | 表示名 | 意味 |
| --- | --- | --- |
| `not_used` | 利用なし | 前払い条件を使わない |
| `proposed` | 条件提示済み | 入居者が前払い可能月数を提示 |
| `manager_confirmed` | 管理会社確認済み | 管理会社が条件を確認 |
| `owner_presented` | オーナー提示済み | 入居安心レポートに反映済み |
| `payment_requested` | 支払い依頼中 | 管理会社等から支払い依頼済み |
| `payment_confirmed` | 入金確認済み | 外部先で入金確認済み |
| `cancelled` | 取消 | 前払い条件を取り下げ |

### 注意

`payment_confirmed` はRentPassが資金を受け取ったことを意味しません。外部先で確認された結果を、管理会社または外部連携から記録した状態です。

## 5. 収納代行ステータス

| Status | 表示名 | 意味 |
| --- | --- | --- |
| `not_used` | 利用なし | 収納代行を使わない |
| `setup_required` | 設定必要 | 収納代行の設定が必要 |

## 6. 家賃リザーブ/信託ステータス

| Status | 表示名 | 意味 |
| --- | --- | --- |
| `not_used` | 利用なし | 家賃リザーブを使わない |
| `proposed` | 提案中 | 管理会社・入居者に提案中 |
| `awaiting_contract` | 契約待ち | 信託/外部保全の契約準備中 |
| `awaiting_deposit` | 入金待ち | 入居者から外部保全先への入金待ち |
| `deposited` | 入金済み | 外部保全先で入金確認済み |
| `releasing` | 月次払い出し中 | 毎月オーナー/管理会社へ払い出し中 |
| `completed` | 完了 | 対象期間の払い出し完了 |
| `refund_pending` | 返還手続き中 | 退去/解約等により未経過分返還中 |
| `refunded` | 返還済み | 未経過分返還済み |
| `cancelled` | 取消 | 利用取消 |


```text

※ RentPassは資金を保有しません。支払いは管理会社指定の方法で行われます。
```

## 10. MVPでやらないこと

- RentPass自身で前払い家賃を預かる。
- RentPass自身で家賃保証を提供する。
- RentPass自身で資金移動業・信託業のような機能を担う。
- 入居者の資産額や通帳画像をオーナーに直接見せる。
- 前払いがあれば必ず入居できる、と保証する。

## 完了条件

- 非預託方針がREADME、docs、型に反映されている。
- 支払い・保証・収納・信託・保険の状態が型定義されている。
- 画面文言でRentPassが資金を預からないことが伝わる。
- 将来の外部API連携に差し替えやすい状態モデルになっている。
