# MVP-25 Stigma-free 文言・免責・説明コピーガイド

RentPassは、入居希望者を「低信用」「危険」「問題あり」と分類するプロダクトではありません。従来の審査では説明しにくい支払い能力や支援体制を、貸主が判断しやすい **対策済み項目** に変換するプロダクトです。

このガイドは、UI、通知、レポート、営業資料、README、LP、利用規約周辺で使う表現を揃えるための文言ルールです。

## 基本メッセージ

> RentPassは、住まいを借りにくい人をスコアで選別するのではなく、貸主が安心して受け入れられる条件を設計するSaaSです。

---

## 1. 使用禁止表現

| NG表現 | 理由 | 代替表現 |
| --- | --- | --- |
| 信用が低い人 | 本人へのスティグマが強い | 従来審査では信用を証明しにくい人 |
| 危険な入居者 | 人格・属性を危険扱いする | 追加の確認・対策が必要な申込 |
| 問題あり | 雑で攻撃的 | 追加確認が必要 |
| 夜職リスク | 職業差別に見える | 収入証明の形式が多様な方 |
| 高齢者リスク | 年齢差別に見える | 見守りや緊急連絡体制が必要な方 |
| 無職リスク | 属性ラベルが強い | 資産・年金・その他収入で支払い能力を確認する方 |
| ブラックリスト | 排除の印象が強い | 受け入れ条件未整備 |
| 審査突破 | 不動産側に警戒される | 貸主が判断しやすい情報を整理 |
| 通る物件 | 承認保証に見える | 相談しやすい物件/条件付きで検討可能な物件 |
| AIが審査 | 説明責任・差別リスクが高い | 判断材料を整理する |

## 2. 推奨表現

| 目的 | 推奨表現 |
| --- | --- |
| プロダクト説明 | 貸せない理由を、貸せる条件に変換する |
| 対象者説明 | 従来審査では信用を証明しにくい方 |
| 管理会社向け | 審査困難な申込を、オーナーに説明可能な入居安心パッケージに変換する |
| オーナー向け | この条件なら受け入れを検討できます |
| 入居者向け | あなたの支払い能力と支援体制を、貸主が確認しやすい形に整理します |
| 見守り | 安否確認の仕組みを整えます |
| 前払い | 支払い対策として前払い条件を提示できます |
| 保証 | 保証会社の利用状況を確認できます |
| 書類 | 確認済み/確認中/追加提出が必要 |
| 承認 | 条件付き承認 |
| 見送り | 今回の条件では受け入れ不可 |

## 3. 画面別コピー

### 入居者オンボーディング

```text
すまいの申込に必要な情報を整理しましょう。
RentPassは、本人確認、収入・資産の確認、前払い条件、見守り、緊急連絡先をまとめて、貸主が判断しやすい形にします。
```

### 信用パス

```text
信用パス完成度

あなたの支払い能力や支援体制を確認するための情報です。
提出する情報は、共有先と目的を確認したうえで利用されます。
```

### 書類アップロード

```text
確認に必要な書類を提出してください。
オーナーには、書類画像そのものではなく「確認済み」などの要約情報が共有されます。
```

### 前払いプラン

```text
前払い条件を設定します。
RentPassは前払い金を預かりません。支払いは管理会社または外部サービスの指定方法で行われます。
```

### 見守り設定

```text
定期的な安否確認を設定します。
未応答が続いた場合は、あらかじめ登録した連絡先へ段階的に通知します。
```

### 入居者チェックイン

```text
お変わりありませんか？

[元気です]
[相談したい]
```

## 4. 管理会社向けコピー

### 申込詳細

```text
入居安心サマリー

この申込について、支払い対策、見守り、緊急連絡体制、保証・保険の状況を確認できます。
不足している項目は、追加提出依頼または受け入れ条件として設定してください。
```

### 受け入れ条件ビルダー

```text
この申込を受け入れるための条件を設計します。
前払い、保証会社、見守り、緊急連絡先、保険を組み合わせて、オーナーに説明できる条件を作成してください。
```

### オーナー共有前プレビュー

```text
オーナーには以下の要約情報だけが共有されます。
本人確認書類、通帳画像、詳細な収入証明、健康情報は表示されません。
```

## 5. オーナー向けコピー

### 入居安心レポート

```text
この申込は、以下の条件を前提に受け入れを検討できます。

- 本人確認済み
- 資産確認済み
- 6か月分前払い条件あり
- 週3回の見守り設定済み
- 緊急連絡先2名確認済み
- 保証会社申請中
```

### 判断ボタン

| ボタン | 文言 |
| --- | --- |
| 承認 | この条件で承認 |
| 条件追加 | 条件を追加して再確認 |
| 見送り | 今回は見送り |

### 注意文言

```text
このレポートは、入居判断に必要な対策状況を要約したものです。
入居の承認を保証するものではありません。
```

## 6. 通知文面

```text

申込の確認に必要な項目があります。
以下のリンクから、追加情報を提出してください。
```

```text

```

```text

```

## 7. 免責・注意文言

### 入居承認について

```text
RentPassは、入居の承認を保証するサービスではありません。
管理会社・オーナーが判断するための情報整理と条件設計を支援します。
```

### 資金について

```text
RentPassは前払い家賃、敷金、保証金等の資金を預かりません。
支払いは管理会社、保証会社、収納代行、信託会社等の外部サービスを通じて行われます。
```

### 見守りについて

```text
RentPassの見守りは、定期的な安否確認と通知・対応ログの管理を支援するものです。
緊急時の救命、訪問、医療対応を保証するものではありません。
```

### 情報開示について

```text
オーナーには、原則として本人確認書類や通帳画像などの生データは表示されません。
共有されるのは、確認済み・対策済みなどの要約情報です。
```

## 8. レビュー観点

UIやドキュメントを追加・変更する際は、以下を確認します。

- [ ] 人を「低信用」「危険」「問題あり」と表現していない
- [ ] 職業・年齢・国籍をリスクラベルとして扱っていない
- [ ] オーナー向けには対策済み項目として表示している
- [ ] 承認保証のような文言になっていない
- [ ] RentPassが資金を預かるように読めない
- [ ] 見守りが救命・駆けつけ保証に読めない
- [ ] 入居者本人が読んでも尊厳を損なわない

## 完了条件

- 使用禁止表現と推奨表現が定義されている。
- 入居者、管理会社、オーナー、通知、免責の文言がある。
- UIレビュー時に使えるチェックリストがある。
