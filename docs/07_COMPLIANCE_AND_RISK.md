# RentPass: 法務・コンプライアンス & リスク管理 (Compliance & Risk)

RentPassが安全かつ持続的に事業を展開するためには、不動産取引、金融規制、居住福祉、個人情報保護に関する厳格な法規制への適合が不可欠です。本ドキュメントでは、関連法規とリスクヘッジ方針を整理します。

---

## 1. 関連法令マトリクスと適合方針

| 関連法令 | 主な規制内容・論点 | RentPassにおける適合方針 |
| :--- | :--- | :--- |
| **資金決済法 / 出資法** | ・預り金規制（無認可での資金預託禁止）<br>・資金移動業 / エスクロー該当性 | **自社では前払い金を一切預からない。**<br>資金の保管・払戻しは提携する**信託銀行・信託会社（エスクロー信託）**または**家賃保証会社＋収納代行**の仕組みを利用し、RentPassは状態可視化SaaSに徹する。 |
| **宅地建物取引業法** | ・不動産媒介・仲介免許の要否<br>・不当な取引条件の禁止 | RentPass自体は賃貸借契約の媒介（仲介）行為を行わず、業務支援プラットフォームとして機能。仲介手数料ではなく**SaaS利用料およびシステム利用料**を受領。 |
| **改正住宅セーフティネット法** (2025年施行) | ・住宅確保要配慮者の入居円滑化<br>・居住サポート住宅制度<br>・認定家賃債務保証業者制度 | 改正法の基準に完全準拠した安否見守り・残置物合意・認定保証会社連携のワークフローを提供し、管理会社の「居住サポート住宅」登録を強力にサポート。 |
| **借地借家法** | ・借家人保護（正当事由・解除制限）<br>・賃料前払い特約の有効性 | 家賃前払い特約および残置物処理特約が借地借家法違反（借家人に不利な特約の無効）とならないよう、国交省標準モデル条項を採用。 |
| **個人情報保護法 / 信用分野GL** | ・機微情報（要配慮個人情報）の取得制限<br>・第三者提供時の同意取得 | 代替与信・安否ログ・緊急連絡先情報の取得時に明確な利用目的を明示し、電子同意を取得。RLSによる厳格なアクセス制御を実施。 |

## 2. 差別・ラベリングリスクへの配慮方針

- **呼称の厳格化**:
  「信用が低い人」という表現は社内外で一切使用せず、**「従来の審査では信用を証明しにくい人（多様な働き方・単身シニア）」** と定義。
- **ポジティブな与信設計**:
  欠点を暴くための審査ではなく、**「どうすれば貸主が安心して鍵を渡せるか」** という解決策（ソリューション条件）の設計に特化。

## 3. 万一の事故発生時における法的免責・対応スキーム

```
  [事故・異変発生 (レベル3アラート: 48時間未応答)]
                        │
                        ▼
  [居住支援法人 / 駆けつけ事業者による現地確認]
                        │
         ┌──────────────┴──────────────┐
         ▼                             ▼
   【安否確認・無事】             【死亡・緊急搬送確認】
         │                             │
   ・アラート解除                ・警察・救急への連絡
   ・原因記録 & 見守り再開        ・緊急連絡先・親族への連絡
                                       │
                                       ▼
                       【国交省ガイドライン準拠 残置物処理】
                       ・電子委任合意に基づき受任者が適正処理
                       ・原状回復・敷金精算 / 保証会社求償
```

1. **安否確認システムの免責事項**:
   RentPassは警備業法上の警備サービスや医療行為ではなく、日々の連絡見守り支援システムであることを利用規約に明記。
2. **残置物処理の合意効力**:
   令和3年（2021年）国交省策定「残置物の処理等に関するモデル契約条項」に基づく受任者指定（居住支援法人等）を行い、不法投棄・住居侵入・財産権侵害のリスクを排除。
