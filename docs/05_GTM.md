# RentPass: Go-To-Market (GTM) 戦略 & アライアンス計画

本ドキュメントでは、RentPassを初期市場に浸透させ、管理会社・保証会社・オーナー・入居者のエコシステムを構築するためのGTM戦略を定義します。

---

  ┌─────────────────────────┐
  │ Phase 1: 高齢者見守り特化 │ ──▶ 2025年改正住宅セーフティネット法を追い風に
  │ (Senior Assisted MVP)   │     管理会社・居住支援法人・シニア仲介へ導入

  └─────────────────────────┘

## 2. 初期ターゲットセグメント（なぜ高齢者から入るのか？）

1. **法制度の強力な後押し**:
   2025年10月施行の改正住宅セーフティネット法により、高齢者等の入居を拒まない「居住サポート住宅」制度や認定家賃債務保証業者制度が創設。管理会社・オーナーにとって見守り・残置物対策の導入が急務。
2. **課題の痛烈さ**:
   単身高齢者の孤独死・残置物放置による損害は、オーナーにとって「一度起きたら取り返しのつかない致命傷」。リスクヘッジへの支払い意欲が最も高い。
3. **行政・居住支援法人からの送客**:
   自治体の福祉窓口や居住支援法人とのアライアンスにより、広告費をかけずに優良な入居希望者を獲得可能。

## 3. アライアンス・パートナーシップ構造

### 3.1 家賃保証会社（Casa、全保連、ジェイリース等）
- **メリット**: RentPassの見守り・前払いリザーブにより事故率が激減。
- **連携形式**: RentPass専用プランの共同提供、保証審査におけるスコア優遇。

### 3.2 信託銀行・信託会社（りそな信託、三菱UFJ信託等）
- **メリット**: 新たな小口エスクロー信託市場の開拓。
- **連携形式**: RentPass API経由での分別管理口座の自動払い出し管理。

### 3.3 居住支援法人・訪問駆けつけサービス
- **メリット**: 地域見守り案件の受託拡大。
- **連携形式**: レベル3アラート（48時間未応答時）の現地駆けつけ業務提携。

## 4. 獲得ファネル & KPI

| ファネル階層 | アクション | 主要KPI |
| :--- | :--- | :--- |
| **Top (認知・リード獲得)** | 管理会社向け「孤独死・残置物対策セミナー」、宅建協会連携 | セミナー参加企業数、問い合わせ数 |
| **Middle (トライアル)** | 管理会社向けフリーミアム（10戸まで見守り無料） | アカウント登録数、物件・入居者登録数 |
| **Bottom (成約・拡張)** | 有料管理プランへの移行（室数課金） & 保全信託案件成約 | 有料契約管理室数、MRR / ARR、LTV |
| **Retention (継続)** | 安否確認チェックイン継続率、アラート解決率 | 解約率（Churn Rate < 0.5%）、NPS |
